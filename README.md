# Operación y Puntualidad de Vuelos Comerciales en Estados Unidos (2024)

Repositorio oficial del proyecto final para el *Diplomado en Introducción Analítica a la Ciencia de Datos* (Módulo 8: Comunicación de Resultados).

Este proyecto investiga la dinámica temporal, espacial y operativa de los retrasos en vuelos comerciales domésticos de Estados Unidos durante el año 2024, evaluando la viabilidad técnica de estimar la probabilidad de una demora crítica >15 minutos) antes del despegue utilizando modelos de aprendizaje automático supervisado.

URL del dashboard: https://emartlion.github.io/vuelos_2024/
